# WOW SCHOOL · Beginner · Revise & Check 7&8

Интерактивный модуль для самостоятельного закрепления материала после Units 7–8.

## Что повторяет ученик
- word order in questions: `be` и present simple
- common free-time verb phrases
- imperatives и object pronouns: `me / him / her / it / us / them`
- `can / can’t` для permission / possibility
- `like / love / hate + verb-ing`
- activities и ключевые звуки Units 7–8
- короткое чтение с опорой на уже знакомую лексику

## 8 блоков
1. **Question Lab** — выбрать грамматически правильный вопрос по черновику.
2. **Weekend Board** — соединить activity с правильным глаголом `play / go / do / other`.
3. **Director’s Cut** — кино-механика с imperatives и object pronouns; правильный ответ запускает clapperboard-анимацию.
4. **Permission Gate** — can / can’t в бытовых ситуациях; шлагбаум визуально открывается или остаётся закрытым.
5. **Sentence Builder** — один обязательный блок сборки предложений; русский перевод + British English model audio.
6. **Sound Check** — прослушать слово и выбрать ключевой звук из Units 7–8; waveform-анимация.
7. **Weekend Story** — короткий Beginner reading; текст виден сразу, TTS является дополнительной опорой. Под визуал предусмотрен portrait 9:16.
8. **Skill Passport** — signature-блок: шесть мини-checkpoints по ключевым темам; каждый правильный ответ ставит анимированный штамп.

## Визуальная идея
Вместо cooking-layer из Unit 8B здесь используется **Review / Checkpoint layer**: галочки, карточки повторения, clapperboard, дорожные знаки, audio-wave, stamps и passport/checkpoint мотив. Общая структура WOW SCHOOL остаётся прежней.

## Навигация для проверки
- `Alt + Shift + →` — следующее задание внутри блока
- `Alt + Shift + ←` — предыдущее задание внутри блока
- `Alt + Ctrl + →` — следующий блок
- `Alt + Ctrl + ←` — предыдущий блок
- `Ctrl + Alt + D` — показать / скрыть dev-панель

## Запуск
Открой `index.html` или размести папку на GitHub Pages. Готовый iframe находится в `iframe.txt`.

Base canvas: **1600×900**. Модуль масштабируется целиком и не требует page-scroll.
