# WOW SCHOOL · Beginner · Unit 4A · Meet the family

Interactive module based on **English File 4th Edition Beginner, Unit 4A**.

## Repository structure
Upload the whole folder **`Beginner_Unit4A_Meet_the_family/`** into the root of the repository **`WOW-SCHOOL/module_beginner`**.

Expected public URL after GitHub Pages is enabled:
`https://wow-school.github.io/module_beginner/Beginner_Unit4A_Meet_the_family/`

## Module structure
7 blocks + Results:
1. Family Vocabulary — 10 tasks
2. Sounds & Pronunciation — 8 tasks
3. Possessive Adjectives + Possessive ’s — 10 tasks
4. Family Match — 8 matching pairs (**new interactive block**)
5. Reading Mission — 6 tasks
6. Listening Mission — 8 tasks
7. Family Snapshot Review — 8 tasks

Total: **58 scored elements**.

## Pedagogical focus
- Vocabulary: people and family
- Grammar: possessive adjectives, possessive ’s
- Pronunciation: **/ʌ/**, **/æ/**, **/ə/**
- Contexts from the unit: babysitter / family, birthday card, family photo

## Fixed layout rules for all future modules
1. The **bottom progress area** (task dots + “Задание X из Y”) must always stay visible.
2. Long prompts must **not push progress off the slide**.
3. Images must always use **object-fit: contain** and stay fully visible.
4. If a reading text is longer, the image may be smaller and the text may sit **next to the image**, not only below it.

## Images
This archive is ready **without final generated images**. Place final images into `assets/images/` using the exact filenames from `VISUAL_MANIFEST.json` and `IMAGE_PROMPTS.md`.

## Audio
The module uses short British-English synthesis for stable playback. Listening and reading are split into short chunks.
