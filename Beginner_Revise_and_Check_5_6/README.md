# WOW SCHOOL · Beginner · Revise & Check 5&6

Готовый интерактивный модуль для самостоятельного закрепления после Units 5–6 English File Beginner.

## Что внутри
- 8 учебных блоков + единый results screen;
- British English TTS (`en-GB`) в логике проекта;
- подсказки и transcript по желанию;
- сохранение прогресса в `localStorage`;
- скрытая навигация для быстрой проверки;
- fallback-визуалы: модуль работает до добавления финальных фотографий.

## Блоки
1. **Grammar Mix** — present simple: I/you/we/they, he/she/it, отрицания, вопросы, adverbs of frequency.
2. **Food & Drink Match** — соединение English ↔ Русский с анимированной линией.
3. **Routine Sort** — распределение действий по Morning / Day / Evening.
4. **Pronunciation Lab** — звуки и word stress.
5. **A Busy Morning** — reading + optional TTS + вопросы.
6. **Sentence Builder** — сборка фраз из слов + русский смысл + модель произношения.
7. **At Breakfast** — короткий beginner-friendly dialogue + скрываемый transcript.
8. **Life Snapshot** — signature-блок: раскрытие 1–3 clues и определение профиля человека.

## Горячие клавиши для проверки
- `Alt + Shift + →` — следующее задание внутри блока
- `Alt + Shift + ←` — предыдущее задание внутри блока
- `Alt + Ctrl + →` — следующий блок
- `Alt + Ctrl + ←` — предыдущий блок
- `Ctrl + Shift + D` — показать / скрыть QA-навигацию
