# WOW SCHOOL · Beginner · Unit 5A · A big breakfast?

A full interactive module for the `module_beginner` repository.

## Blocks
1. Breakfast Basics — very short and simple listening dialogue
2. Food & Drink — 12 audio-supported vocabulary tasks
3. Breakfast Sort — 12 drag / tap-to-place cards in 3 columns
4. Sentence Builder — 8 present simple sentence-building tasks + model audio
5. Reading Mission — 6 questions + visible text + full text audio
6. Pronunciation — 10 tasks with /dʒ/ and /ɡ/
7. Listening Mission — 8 questions across two short breakfast dialogues
8. **NEW:** Breakfast Match — visible English ↔ Russian pair matching

## Important
- British-English synthesis is preserved.
- Sentence builder is included as a base mechanic.
- The last learning block is experimental, but simpler and clearer than the Unit 4B dice mechanic.
- Images are included as placeholders and can later be replaced with final generated visuals using the same filenames.
