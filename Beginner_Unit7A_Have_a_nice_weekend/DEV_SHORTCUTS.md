# Hidden QA navigation

This file is internal and is not shown in the student UI.

- `Ctrl + Alt + D` — toggle hidden developer bar
- `Alt + Shift + →` — next task inside current block
- `Alt + Shift + ←` — previous task inside current block
- `Alt + Ctrl + →` — next block
- `Alt + Ctrl + ←` — previous block
- Double-click the Unit 7A badge — toggle hidden developer bar

Optional direct QA URLs:
- `?screen=1` … `?screen=8`
- add `&idx=0`, `&idx=1`, etc. for sequential task blocks
