# WOW SCHOOL · Beginner · Unit 7A · Have a nice weekend!

Interactive post-lesson reinforcement module for WOW SCHOOL.

## Language focus
- word order in questions with **be** and **present simple do / does**;
- common free-time verb phrases;
- pronunciation practice with `/w/`, `/h/`, `/eə/`, `/aʊ/`;
- short reading and listening about weekends.

All exercise texts and dialogues in this module are newly written for the WOW SCHOOL reinforcement module.

## Blocks
1. Weekend Warm-up — audio → free-time phrase
2. Question Builder — mandatory word-order sentence/question builder
3. Question Switch — two-step BE vs DO/DOES mechanism
4. Weekend Interview — short listening + optional transcript + hint
5. Weekend Reading — bounded reading + questions
6. Sound Lab — 4-column pronunciation sort with tap/drag fallback
7. Weekend Chat — chat simulator with natural replies
8. Weekend Planner — signature listening + Saturday/Sunday schedule interaction

## Images
The initial archive is intentionally prepared **without final lesson photography**. The module has visual fallbacks. Generate the files listed in `IMAGE_PROMPTS.md` / `VISUAL_MANIFEST.json`, then place them in `assets/images/` without changing filenames.
