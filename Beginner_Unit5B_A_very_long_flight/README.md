# WOW SCHOOL · Beginner · Unit 5B · A very long flight

A full interactive module for the `module_beginner` repository.

## Blocks
1. Travel Essentials — easy English → Russian travel vocabulary with single-word audio
2. Airport Words — 12 audio-supported vocabulary tasks
3. Travel Sort — 12 drag / tap-to-place cards in 3 columns
4. Sentence Builder — 8 travel routine sentence-building tasks + model audio
5. Reading Mission — 6 questions + visible text + full text audio
6. Pronunciation — 10 tasks with /aɪ/ and /eɪ/
7. Listening Mission — 8 questions across two short travel dialogues
8. **NEW:** Error Hunter — find the mistake, fix it, then hear the correct sentence

## Important
- British-English synthesis is preserved.
- Sentence builder is included as a base mechanic.
- The last learning block is experimental and new for this module.
- Images included in this archive are placeholders; final visual generation prompts are stored in `IMAGE_PROMPTS.md`.
