# WOW SCHOOL · Beginner · Unit 6A · A school reunion

Готовый интерактивный модуль для репозитория `WOW-SCHOOL/module_beginner`.

## Структура
1. **Jobs** — 10 заданий на профессии + британское произношение.
2. **Job Match** — 8 пар English ↔ Русский, по 4 пары в раунде, с анимированными линиями.
3. **Present Simple** — 10 заданий на `he / she / it`, `does / doesn’t`, `-s / -es` + кнопка «Правило».
4. **Third Person -s** — 9 аудиозаданий на `/s/`, `/z/`, `/ɪz/`.
5. **English at Work** — короткое чтение уровня Beginner, текст всегда виден, есть аудио и точечные подсказки.
6. **Sentence Builder** — 8 заданий: русский смысл → собрать английское предложение → прослушать модель.
7. **School Reunion** — короткий диалог, 6 вопросов, British English TTS, скрываемый текст и подсказки.
8. **Reunion Passport** — новый интерактив: по подсказке выбрать профессию + место работы; правильный профиль получает визуальный штамп.

После восьмого блока открывается стандартная страница результатов.

## Для проверки разработчиком
Скрытые сочетания клавиш работают без выполнения заданий:
- `Alt + Shift + → / ←` — следующее / предыдущее задание внутри блока.
- `Alt + Ctrl + → / ←` — следующий / предыдущий блок.
- `Ctrl + Shift + D` — показать / скрыть маленькую панель навигации разработчика.

Для прямой проверки экрана можно локально использовать `?dev=1&screen=5&task=2`.

## Изображения
Модуль уже работает без финальных фото: вместо отсутствующих файлов отображается аккуратный тематический fallback. После генерации просто положите изображения в `assets/images/` по именам из `VISUAL_MANIFEST.json` / `IMAGE_PROMPTS.md` — код менять не нужно.

Все фото в модуле подключены через `<img>` и отображаются с `object-fit: contain`.
