# WOW SCHOOL · Beginner · Unit 7B · Lights, camera, action!

Interactive reinforcement module for students after the lesson.

## Curriculum focus
- imperatives
- object pronouns: me, him, her, it, us, them, you
- kinds of films
- sentence rhythm

## 8 blocks
1. Movie Genres — easy film vocabulary warm-up with flip-poster feedback.
2. Director Says — imperatives on a film set.
3. Pronoun Close-up — object pronouns.
4. Sentence Builder — mandatory sentence-building mechanic with Russian cue + British English audio model.
5. Script Reading — short original film-set scene with audio; names are visible in text, but TTS reads only the lines.
6. Rhythm Take — tap the strong words in short film-set phrases.
7. Studio Talk — short dialogue + hidden transcript + pronoun reference.
8. Action Challenge — signature interactive film-set task with camera flash, film-strip progress, and clickable targets.

Base canvas: 1600×900. No page scrolling. Student-facing UI only. Hidden developer shortcuts remain available for QA.
