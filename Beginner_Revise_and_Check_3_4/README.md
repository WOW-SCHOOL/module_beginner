# WOW SCHOOL · English File Beginner · Revise & Check 3&4

Interactive review module built for `WOW-SCHOOL/module_beginner`.

## Public path
`https://wow-school.github.io/module_beginner/Beginner_Revise_and_Check_3_4/?v=1`

## Source basis
The review is an adapted WOW SCHOOL interactive module based on the scope of English File Beginner Units 3–4 and the official Revise & Check 3&4 categories: grammar from Files 3–4; small things and souvenirs; family; irregular plurals; colours and opposite adjectives; pronunciation review; reading; and short real-life interviews.

## Module structure
1. Quick Review — small things & souvenirs (10)
2. Grammar Check — Units 3–4 grammar (10)
3. Review Sort — 16 draggable / tap-to-place words in 4 columns
4. Sentence Builder — 8 Russian-to-English word-order tasks + audio model
5. Reading Mission — short accessible text + optional audio + 6 questions
6. Pronunciation Lab — 10 short audio tasks
7. Street Interviews — 8 micro-listening tasks with optional transcript support
8. Error Hunter — NEW experimental mechanic: find the wrong word, then repair it (8)
9. Results — unchanged WOW SCHOOL results pattern from Unit 4B

## Beginner listening rule
This module deliberately avoids beginning with a long unseen listening. Listening appears later and is split into short, context-rich clips. Block 7 includes optional transcript support.
