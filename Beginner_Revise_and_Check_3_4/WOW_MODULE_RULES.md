# WOW SCHOOL · MODULE RULES (Beginner baseline)

These rules are mandatory for future Beginner modules unless the lesson itself requires a deliberate exception.

1. **Keep the Unit 4B speech synthesis exactly as the base.** British-English TTS, same providers, same fallback order, same short-chunk splitting. Do not replace it with local WAV files or a different browser voice.
2. **Use audio often, but at Beginner level keep it achievable.** Vocabulary, pronunciation, model phrases, short dialogues, and reading audio are encouraged. Do not begin early Beginner modules with a long unseen listening passage.
3. **Long listening without visible text is postponed.** For early Beginner (roughly before Units 7–8), listening should be short, highly contextual, or offer optional text support. Longer unsupported listening belongs later or at Elementary.
4. **Sentence Builder is now a core block.** Every following module should include a word-order sentence-building activity with a Russian cue and a British-English audio model.
5. **Bottom progress is sacred.** Task dots / “Задание X из Y” must always remain visible. Long prompts or answer lists may shrink or scroll inside their own area, but progress must never disappear below the slide.
6. **Images are never cropped.** Always use `object-fit: contain`. If necessary, reduce the visual frame rather than crop faces, hands, objects, or important context.
7. **Reading layout is flexible.** Text may sit beside the image. For the main reading block (usually Block 5), prefer a **portrait / selfie image, 9:16**, with the text beside it.
8. **Do not overuse multiple choice.** Keep a mix of sorting, columns, sentence building, audio recognition, matching, repair/fix mechanics, and other interactions.
9. **Keep the classic columns activity available.** A tap / drag word-sorting block is part of the core WOW SCHOOL interaction library and should be reused where it genuinely supports the language.
10. **One new experimental block per module.** The last learning block should introduce a clear mechanic not used in the previous module. Instructions must make the order of actions obvious. No ambiguous multi-step flow.
11. **Target audience:** mainly teens and adults approximately **16–45**, so visuals and mechanics should feel modern, useful, and not childish.
12. **Final Results slide is a base component.** Keep the Unit 4B results structure, percentage ring, section bars, strongest / review recommendations, retry and home buttons.
13. **Repository structure:** every Beginner module lives as its own folder in `WOW-SCHOOL/module_beginner`.
14. **Visual workflow:** first build and test the module without photos, then generate images to exact filenames / ratios, then merge images into the finished archive.
