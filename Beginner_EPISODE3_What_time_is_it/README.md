# WOW SCHOOL · English File Beginner · Episode 3 · What time is it?

Interactive module built for `WOW-SCHOOL/module_beginner`.

## Public path
`https://wow-school.github.io/module_beginner/Beginner_EPISODE3_What_time_is_it/?v=4`

## Source basis
The module is adapted from **English File Beginner, Practical English Episode 3: What time is it?**
Core content used in simplified WOW SCHOOL form:
- Rob Walker short dialogues about the time, the train, and the meeting
- time expressions such as *o'clock*, *half past*, *quarter past*, *quarter to*, *five past*, *twenty to*
- short follow-up situation with Amy and Jenny

## Module structure
1. **Clock Setter** — the learner drags the clock hands and sets the time
2. **Time Match** — English phrases on the left, Russian translations on the right, with visual connections
3. **Rob's Story** — short practical dialogues with optional transcript support
4. **Sentence Builder** — one single builder block for this module, as requested
5. **What time's the show?** — short visible text + optional audio support
6. **Time Listening** — short listening questions about time expressions and key phrases
7. **Daily Planner** — place everyday activities into the correct time slots
8. **Clock Challenge** — experimental final block: listen first, then set the time on the interactive clock
9. **Results** — unchanged WOW SCHOOL results logic

## Key implementation idea
The main experiment in this module is **visual work with the clock face itself**. The learner does not only read or choose a time but physically moves the hands. The last block raises the difficulty slightly: the text support is hidden by default, and the learner should first rely on audio.
