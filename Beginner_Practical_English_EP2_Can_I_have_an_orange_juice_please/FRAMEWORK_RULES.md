# WOW SCHOOL module framework rules

1. Keep the module on a fixed 1600×900 canvas and scale the whole canvas to the available viewport.
2. Never introduce page scrolling inside Holst.
3. Reuse the established WOW SCHOOL layout and interaction patterns; do not rebuild the framework between modules.
4. Keep feedback and task progress visible in the right panel at all times.
5. Use the established British English Google TTS engine with short chunks; do not replace it with browser voices.
6. Pronunciation blocks should prioritize the interactive task; decorative photos are optional and should be omitted when they add no learning value.
7. Every build must pass a runtime smoke test for all screens before delivery.
