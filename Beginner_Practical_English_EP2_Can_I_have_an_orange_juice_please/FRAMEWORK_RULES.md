# WOW SCHOOL fixed framework rules

1. Every module renders on a fixed **1600×900 (16:9)** canvas and scales to the available viewport. The page itself must never scroll vertically or horizontally inside Holst.
2. Use the established **Google Translate TTS en-GB audio provider chain**, split into short chunks. Do not replace it with browser SpeechSynthesis voices.
3. Preserve the approved WOW SCHOOL shell, feedback/progress placement, image-fit rules, and interaction patterns unless the user explicitly requests a redesign.
