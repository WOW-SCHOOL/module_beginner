# Промпты для генерации изображений — Beginner · Unit 6B · Good morning, goodnight

## Общее правило для ВСЕХ изображений
Сгенерируй **каждое изображение отдельным файлом**. **Не делай коллаж. Не делай один общий лист с несколькими картинками. Не вырезай отдельные кадры из коллажа.** Для каждого пункта ниже нужно создать **отдельное самостоятельное изображение**.

Общий визуальный стиль: яркая, сочная, современная, премиальная lifestyle-фотография; реалистичные люди; естественные позы; тёплый свет; современная визуальная эстетика 2026; живые и разные локации; разные люди в кадрах; без неестественных AI-ляпов; без водяных знаков; без логотипов брендов; без детской стилистики; без пустых огромных зон; все важные объекты держать в safe area 10–12%; изображения должны хорошо смотреться с `object-fit: contain` и **не требовать кропа**.

Тема модуля: **Beginner · Unit 6B · Good morning, goodnight**. Визуально поддерживаем тему: morning routine, a typical day, breakfast, work, café, evening routine, saying good morning / good night, лёгкое общение, распорядок дня.
