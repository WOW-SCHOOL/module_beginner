# DEV SHORTCUTS

## Toggle hidden developer mode
- Double-click the Unit 6B badge
- or press `Ctrl + Alt + D`

## Navigation
- `Alt + Shift + →` — next task inside the current block
- `Alt + Shift + ←` — previous task inside the current block
- `Alt + Ctrl + →` — next block
- `Alt + Ctrl + ←` — previous block
