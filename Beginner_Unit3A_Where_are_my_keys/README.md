## Module structure
1. Small Things — vocabulary
2. Singular, Plural & a/an — grammar
3. Pronunciation Lab — /z/, /s/, /ɪz/
4. What’s in your bag? — functional English
5. Reading: The Missing Keys
6. Memory Match — singular ↔ plural
7. Listening Mission — two short dialogues
8. Results

## Audio
Audio uses the same short-fragment TTS logic as previous WOW SCHOOL modules. Longer texts are deliberately split into short chunks to reduce playback failures.

## Visuals
This build intentionally contains **no lesson photographs**. Abstract in-module visuals are used temporarily. Final generated images can be inserted later without changing the exercise logic.


## Final visuals
All generated Unit 3A visuals are inserted into the start screen and lesson blocks. Images use rounded containers and safe fit rules.
