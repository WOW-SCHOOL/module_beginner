# Hidden developer shortcuts

These controls are for WOW SCHOOL QA and are not shown to students by default.

- `Ctrl + Alt + D` — show / hide developer navigation bar.
- `Alt + Shift + →` — next task inside the current block.
- `Alt + Shift + ←` — previous task inside the current block.
- `Alt + Ctrl + →` — next block.
- `Alt + Ctrl + ←` — previous block.
- Double-click the `Episode 4` badge — show / hide developer navigation bar.

Direct QA links also work: `?screen=1&idx=0`.
For Block 3, `idx=0` or `idx=1` selects the matching round.
