# WOW SCHOOL · Beginner · Unit 8A · Can I park here?

Полностью переработанный модуль с новой тематикой и новой последовательностью упражнений.

## Логика обучения
Сначала ученик знакомится с ключевой лексикой и переводом, затем узнаёт эти слова в городских знаках, после этого переходит к can / can’t, строит фразы, тренирует слух, слушает короткие диалоги, проходит driving test и завершает модуль финальной городской картой.

## 8 блоков
1. **Road Words** — English ↔ Russian matching с анимированными маршрутными линиями.
2. **Sign Decoder** — распознавание знакомой лексики по городским знакам.
3. **Open or Closed?** — can / can’t через анимированный шлагбаум.
4. **Road Builder** — sentence builder в виде дорожной полосы.
5. **Sound Traffic Lights** — различение can / can’t на слух через светофор.
6. **Four Stops** — четыре мини-диалога: train / shop / restaurant / street, скрытый текст под визуалом.
7. **Driving Test** — пошаговая сцена с Anna и examiner; TTS читает только реплики.
8. **City Permit Map** — signature-интерактив: ученик выбирает места на городской карте и слышит готовую модель.
