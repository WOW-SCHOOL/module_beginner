# WOW SCHOOL · Beginner · Unit 8B · I ❤ cooking

Интерактивный модуль для самостоятельного закрепления темы после занятия.

## Что повторяет ученик
- free-time activities
- `like / love / hate / don’t like + verb-ing`
- правила образования `-ing`
- короткие разговорные фразы: `What about you?`, `Me too!`, `Do you like…?`
- pronunciation: `/ʊ/`, `/uː/`, `/ŋ/`
- короткое чтение о занятиях в одиночку и с друзьями

## 8 блоков
1. **Activity Pantry** — лёгкий разогрев по activities.
2. **Preference Recipe** — грамматическая «формула» like / love / hate + -ing.
3. **-ing Kitchen** — тематическая механика: «приготовь» правильную -ing форму; ответ появляется на сковороде.
4. **Table Talk** — естественные короткие реплики о предпочтениях.
5. **Sentence Builder** — обязательная сборка фразы с русским переводом и British English audio model.
6. **Sound Kitchen** — распределение слов по трём «мискам» со звуками `/ʊ/`, `/uː/`, `/ŋ/`.
7. **Alone or Together?** — короткий текст всегда виден; аудио является дополнительной опорой. Для будущей фотографии предусмотрен portrait 9:16.
8. **Hobby Mixer** — signature-механика: сравни интересы трёх кандидатов и найди лучший match; после верного ответа запускается анимация mixer.

## Визуальная тема
Общая структура WOW SCHOOL сохранена, но Unit 8B получил собственный cooking-layer: тёплые food-акценты, kitchen doodles, «рецепты», chopping board, pan, bowls, whisk/mixer и тематические микроанимации. Они поддерживают тему, не подсказывая ответы.

## Запуск
Открой `index.html` или размести папку на GitHub Pages. Для Holst готовый iframe находится в `iframe.txt`.

Base canvas: **1600×900**. Модуль масштабируется целиком и не требует page-scroll.
