# Hidden developer shortcuts

Эти сочетания предназначены для быстрой проверки WOW SCHOOL и не отображаются ученику.

- `Ctrl + Alt + D` — показать / скрыть dev-navigation bar.
- `Alt + Shift + →` — следующее задание внутри текущего блока.
- `Alt + Shift + ←` — предыдущее задание внутри текущего блока.
- `Alt + Ctrl + →` — следующий блок.
- `Alt + Ctrl + ←` — предыдущий блок.
- Double-click по badge `Unit 8B` — показать / скрыть dev-navigation bar.

Для прямой проверки также поддерживается URL-параметр `?screen=1&idx=0`, где `screen=1…8` — номер блока, а `idx` — номер задания с нуля.
