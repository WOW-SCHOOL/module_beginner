# Unit 8B · Краткая механика блоков

## 1. Activity Pantry
Ученик видит русский эквивалент + небольшую тематическую иконку и выбирает правильную activity на английском. После ответа можно прослушать слово / фразу.

## 2. Preference Recipe
Ученик выбирает форму, которая делает предложение грамматически правильным. Визуальная метафора — «рецепт предпочтений»: love / like / don’t like / hate + activity in -ing.

## 3. -ing Kitchen
Signature visual mechanic №1. Слева «base verb» лежит на chopping board, справа — frying pan. Ученик выбирает правильное написание `-ing`; при верном ответе готовая форма появляется на сковороде с короткой анимацией.

## 4. Table Talk
Короткие, понятные Beginner-реплики. Нужно выбрать естественный ответ: `What about you?`, `Me too!`, `Yes, I do.`, `No, I don’t.` и т. п. Есть British English TTS.

## 5. Sentence Builder
Один обязательный Sentence Builder на весь модуль. Есть русский перевод, отдельные слова, проверка порядка и British English model audio.

## 6. Sound Kitchen
Signature visual mechanic №2. Слово можно кликнуть / перетащить в одну из трёх «мисок»: `/ʊ/`, `/uː/`, `/ŋ/`. Drag дублируется tap-механикой, поэтому блок удобен и с мышью, и на touch-screen.

## 7. Alone or Together?
Короткий текст Beginner виден сразу — нет сложного audio-only listening. Ученик читает и отвечает на 6 вопросов. TTS текста — дополнительная опора. Слева используется отдельный portrait visual 9:16.

## 8. Hobby Mixer
Финальный signature-блок в контексте preferences / dating-profile из Unit 8B. У основного профиля есть три предпочтения. Нужно найти кандидата с максимально похожим сочетанием love / like / hate. Верный match запускает тематическую mixer-анимацию.
